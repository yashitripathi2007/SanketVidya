For the complete documentation including architecture details, user credentials, and root configurations, please refer to the main [Root README.md](../README.md).

---

## 🚀 How to Run Locally

### 1. Install Dependencies
Run the install command inside this directory:
```bash
npm install
```

### 2. Start the Development Server
Run the dev command:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 🛠️ Tech Stack & Structure
*   **Framework:** Next.js 16 (App Router)
*   **State & Auth:** Client-side local storage integration with pre-seeded demo users.
*   **Styles:** Tailwind CSS 4
*   **Locales:** `en`, `gu`, `hi` (`next-intl`)
